# Earth Jukebox

NASA Space Apps Challenge 2026 (Nov 14-15) entry for **The Earth Information Jukebox**.
Challenge: https://www.spaceappschallenge.org/2026/challenges/the-earth-information-jukebox/

Turn NASA Earth Information Center (EIC) visual frames into dynamic, musically pleasing sonifications,
so anyone (including blind and low-vision users) can experience Earth science through sound.

### Time coverage (from SVS API metadata, checked 2026-11-14)

| Visual | Data period | Time step | Notes |
|---|---|---|---|
| Night Lights | 2012 to 2023 | 1 frame per year (annual averages), then change map | 12 steps, + zooms on India, Ukraine, W. Europe, E. Med |
| Sea Surface Currents (ECCO2) | 2007-03-25 to 2008-03-03 | model, ~daily | ~1 year, no overlap with others |
| GEOS Aerosols | 2025-08-19 20:00 UTC | **single still** | No time axis. Music must scan space, not time |
| Air Quality (GEOS-CF) | unclear in metadata | model frames (~740) | Check page before using |
| Perpetual Ocean 2 | 2021-01-15 to 2023-12-25 | model, ~daily | Camera zooms (Kuroshio, Agulhas, Gulf Stream) |
| DYAMOND CO2 | 2020 Jan to Mar | model, sub-daily | Camera orbits/zooms |
| ISS Lightning | 2017-01 (or 03) to 2023-07 | 10-day rolling window | ~6.5 years, seasons visible |
| Atmospheric River 3D | single event, model (MERRA-2 era) | hourly model | Narrated movie, camera moves |
| GEDI Forest Height | 2019-04 to 2020-04 | **static composite** | No time axis |
| Caldwell 73 | n/a | n/a | Reference sonification only |

Overlap windows:
- **2021 to 2023**: Night Lights (3 annual frames) + Lightning (to Jul 2023) + Perpetual Ocean 2. Only 3-way overlap.
- **2020 Jan to Mar**: CO2 + Lightning + Night Lights (2020 frame).
- **2019-04 to 2020-04**: GEDI (static) + Lightning + Night Lights.

Caveats: frame index is not always time (camera moves, zooms, title cards), steps differ (annual vs 10-day vs daily), and two items are stills.

## Pipeline sketch

1. Fetch frames (SVS API, or `ffmpeg` frame extraction from MP4).
2. Per frame: sample regions, brightness, hot-pixel counts, frame-to-frame motion.
3. Colorbar lookup: pixel colour to real value.
4. Musical rules (scale, chords, tempo, instruments) drive a synth (Tone.js in browser).
5. Jukebox UI: pick a visual, watch it play with its soundscape. Accessible (screen reader, descriptive text).
